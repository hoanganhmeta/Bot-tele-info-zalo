# 🤖 Zalo Telegram Bot

Bot Telegram lấy thông tin tài khoản Zalo thông qua OAuth 2.0.

## 🚀 Tính năng

- Đăng nhập Zalo qua OAuth
- Lấy thông tin user: ID, Name, Email, Gender, Birthday, Avatar
- Tự động refresh token
